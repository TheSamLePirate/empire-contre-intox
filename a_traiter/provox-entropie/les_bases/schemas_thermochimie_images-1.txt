2. Enthalpie – H = U + PV
   Description : Diagramme montrant le passage de l’énergie interne U à l’enthalpie H par l’ajout du terme PV. Axes et flèches indiquant la relation H = U + PV. Labels français « Énergie interne U » et « Enthalpie H ».
   Image ID : MNu2M

3. Loi de Hess
   Description : Schéma illustrant la loi de Hess. État initial relié à l’état final par un chemin direct et par un chemin passant par un ou plusieurs intermédiaires. Indication claire que la somme des ΔH des étapes (ΔH1 + ΔH2 + …) est égale au ΔH total de la réaction globale.
   Image ID : uWaxY

4. Enthalpie libre de Gibbs – G = H – TS
   Description : Schéma de la définition de l’enthalpie libre de Gibbs. Formule G = H – TS mise en évidence avec les labels « Enthalpie H » et « Enthalpie libre de Gibbs G ». Flèches indiquant la soustraction du terme TS.
   Image ID : St7Sp

5. Énergie libre de Helmholtz – F = U – TS
   Description : Schéma de la définition de l’énergie libre de Helmholtz. Formule F = U – TS avec les labels « Énergie interne U » et « Énergie libre de Helmholtz F ». Indication du terme entropique TS soustrait.
   Image ID : u1nIc

6. Critères de spontanéité (ΔG)
   Description : Tableau ou schéma en trois colonnes clairement séparées :
   - ΔG < 0 → Réaction spontanée
   - ΔG = 0 → Équilibre
   - ΔG > 0 → Réaction non spontanée
   Labels entièrement en français.
   Image ID : mKp69

7. Les quatre potentiels thermodynamiques (U, H, F, G)
   Description : Schéma des quatre potentiels thermodynamiques fondamentaux : Énergie interne U, Enthalpie H, Énergie libre de Helmholtz F et Enthalpie libre de Gibbs G. Flèches indiquant les transformées de Legendre qui permettent de passer de l’un à l’autre.
   Image ID : mH0oZ

8. Relations de Maxwell (carré thermodynamique)
   Description : Carré thermodynamique (thermodynamic square) présentant les quatre potentiels U, H, F, G aux coins. Différentielles dU, dH, dF, dG écrites ainsi que les quatre relations de Maxwell qui en découlent. Labels en français.
   Image ID : rgb8w

9. Cycle de Rankine
   Description : Schéma du cycle de Rankine idéalisé avec les quatre organes principaux : Pompe, Chaudière, Turbine et Condenseur. Points numérotés 1-2-3-4 et flèches indiquant le sens du cycle ainsi que les échanges de chaleur et de travail.
   Image ID : i7IeX

10. Cycle de Carnot
    Description : Diagramme T-S du cycle de Carnot. Deux isothermes (source chaude Th et source froide Tc) et deux adiabatiques. Labels « Source chaude Th », « Source froide Tc » et « Cycle de Carnot ». Axes température et entropie.
