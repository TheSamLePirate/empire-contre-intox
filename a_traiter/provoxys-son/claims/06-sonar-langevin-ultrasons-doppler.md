# Lot 06 — Sonar, Langevin, ultrasons, Doppler (ch. 8, 8b, 8c, 8d)
1. Spallanzani 1793–94 : chauves-souris aveuglées volent, rendues sourdes elles s'écrasent ; Jurine confirme le rôle de l'oreille.
2. Francis Galton, sifflet, 1876.
3. Piézoélectricité : frères Curie 1880 (effet direct), Lippmann prédit l'effet inverse 1881, confirmé par les Curie.
4. Fessenden, 1912–1914, après le Titanic, oscillateur/echo-sounder détectant un iceberg à ~2 miles (essais avril 1914).
5. Langevin & Chilowsky 1915–1917 : hydrophone / projecteur à quartz, détection de sous-marins, premier transducteur ultrasonore de puissance.
6. Sokolov 1929 : contrôle non destructif des métaux par ultrasons.
7. Karl Dussik 1942 : « hyperphonographie », premiers essais d'imagerie crânienne par ultrasons.
8. Howry, Wild, Ian Donald : échographie diagnostique 1950s–1970s.
9. Canal SOFAR découvert dans les années 1940 ; SOSUS ; le son peut voyager des milliers de km à une profondeur donnée.
10. Paul Langevin (1872–1946), élève de Pierre Curie, professeur au Collège de France.
11. d = c Δt / 2 ; c_eau ≈ 1500 m/s ; 2 ms aller-retour ≈ 1,5 m.
12. Production d'ultrasons : quartz, PZT, PVDF, composites ; magnétostriction (nickel, terfénol) ; CMUT ; résonance d'épaisseur f ≈ c_solide/(2e).
13. Z = ρc ; R = (Z2−Z1)/(Z2+Z1) ; Z_air ≈ 400 rayl ; Z_eau/tissu ≈ 1,5×10^6 rayl ; réflexion air/peau ≈ 1 ; le gel est un adaptateur d'impédance.
14. Bandes : 20–100 kHz nettoyage/télémétrie ; 1–5 MHz abdomen/obstétrique/cœur ; 7–18 MHz thyroïde/sein/musculo-squelettique ; dizaines de MHz œil/peau ; lithotritie par chocs focalisés ; HIFU.
15. Atténuation des tissus mous ~0,5 dB·cm⁻¹·MHz⁻¹ ; résolution axiale ≈ cτ/2.
16. Modes A, B, M, Doppler (continu, pulsé, couleur, puissance), harmonique tissulaire ; indices TI et MI, principe ALARA.
17. Doppler 1842 (Prague, mémoire sur les étoiles binaires) ; Buys Ballot 1845 : trompettistes sur un train, ligne Utrecht–Maarssen.
18. f' = f (c ± v_o)/(c ∓ v_s) ; à 30 m/s, Δf/f ≈ 9 % ; le balancement total approche/éloignement ≈ 19 % (une tierce mineure).
19. Quand v_s → c : cône de Mach, N-wave ; le bang n'est pas un Doppler.
20. Doppler médical : Δf = 2 v f0 cos θ / c ; à 90°, Δf = 0 ; Δf tombe dans l'audible.
21. Rhinolophe : compensation Doppler (Schnitzler 1968) pour garder l'écho dans la fovéa ~82 kHz.
22. Convention 1540 m/s en tissus mous ; graisse plus lente, os plus rapide, poumon (air) très réfléchissant.
