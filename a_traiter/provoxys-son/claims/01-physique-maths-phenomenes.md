# Lot 01 — Physique de base, mathématiques, phénomènes (ch. 1, 1b, 1c)
1. Dans l'air sec à 20 °C, c ≈ 343 m/s ; air à 0 °C : 331 m/s ; eau douce ~20 °C : ~1480 m/s ; eau de mer ~1500 m/s ; acier ~5000–6000 m/s (longitudinal) ; tissu mou / corps humain : ~1540 m/s (convention de l'échographie).
2. Niveau de pression acoustique : L_p = 20 log10(p/p0) avec p0 = 20 µPa dans l'air.
3. Courbes de Fletcher–Munson datent de 1933.
4. Newton, Principia (1687), pose c = √(P/ρ) (compression isotherme). Avec les valeurs modernes cette formule donne ~280 m/s à 0 °C, 16 % sous la mesure ; Newton lui-même publie 968 pieds/s (1687) puis 979 pieds/s (1713), soit ≈ 295–298 m/s.
5. Laplace corrige (mémoire de 1816, travaux dès ~1802) : processus adiabatique, c = √(γP/ρ), γ = Cp/Cv ≈ 1,40 pour l'air ; √1,4 × 280 ≈ 331 m/s à 0 °C.
6. Colladon & Sturm, lac Léman, 1826 : première mesure sérieuse de la vitesse du son dans l'eau (cloche immergée, chronométrage à la rive opposée).
7. Audible humain typique ~20 Hz – 20 kHz ; bande utile de la parole ~300–3400 Hz ; sensibilité maximale autour de 2–5 kHz.
8. Dans l'air, l'absorption (classique + relaxation N2, O2, H2O) fait croître le coefficient d'atténuation à peu près avec f² dans de larges bandes ; un 50 kHz meurt en quelques mètres d'air humide.
9. Dans l'eau de mer, l'absorption suit la formule de Francois–Garrison (relaxation du borate et du magnésium).
10. Équation d'onde de d'Alembert : 1747 ; solutions f(x−ct)+g(x+ct).
11. Corde : f1 = (1/2L)√(τ/µ), fn = n f1 (lois de Mersenne).
12. Tuyaux : ouvert-ouvert fn = n c/(2L) ; fermé-ouvert seulement les impairs fn = (2n−1)c/(4L) ; d'où la couleur « creuse » de la clarinette.
13. Tempérament égal : fk = f0·2^(k/12) ; demi-ton = 2^(1/12) ≈ 1,05946 ; quinte tempérée 2^(7/12) ≈ 1,4983 au lieu de 1,5 ; écart ≈ 1,96 cent ; cent = 1200 log2(f2/f1).
14. Formule de Sabine : T60 ≈ 0,161 V / A, avec A = Σ αi Si.
15. Écho distinct : retard d'au moins ~50–80 ms, soit un mur à plus de ~10–15 m.
16. c(T) ≈ 331,3 √(1 + T/273,15) m/s (T en °C), soit +0,6 m/s par degré.
17. Le jour (sol chaud) le son se courbe vers le haut (zone d'ombre au sol) ; la nuit ou le soir (inversion de température) il se courbe vers le sol.
18. Le pavillon de l'oreille (~3 cm) ne travaille qu'au-dessus de ~3 kHz.
19. Principe de l'anti-bruit actif : Lueg, 1936.
20. Modes propres d'une salle parallélépipédique : f = (c/2)√((nx/Lx)² + (ny/Ly)² + (nz/Lz)²) ; une chambre de 4 m a son premier mode à ~43 Hz.
21. Fréquence de Schroeder f_S ≈ 2000 √(T60/V), Schroeder 1962.
22. Champ libre, source ponctuelle : −6 dB par doublement de distance ; L_tot = 10 log10 Σ 10^(Li/10) ; 60 dB + 60 dB = 63 dB ; dix sources identiques = +10 dB.
23. Absorption atmosphérique ISO 9613-1 à 20 °C et 70 % d'humidité : de l'ordre de 5 dB/km à 1 kHz, ~30 dB/km à 4 kHz, ~100 dB/km à 8 kHz ; à 40 kHz, plus d'un décibel par mètre.
24. Le tonnerre lointain est grave parce que ses aigus sont absorbés en route.
25. Mars : son faible et sourd, enregistré par Perseverance en 2021 (pression ~6 mbar).
