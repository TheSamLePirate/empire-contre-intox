# Lot 11 — Phonons, espace, Gurnett, astronomie (ch. 13, 14, 14b, 18)
1. Phonon : terme popularisé dans le sillage de Tamm 1932, après Einstein 1907 et Debye 1912 ; supraconductivité BCS par interaction électron-phonon ; effets Raman, Brillouin.
2. Optomécanique : Aspelmeyer, Painter, Kippenberg ; couplage phonon–qubit.
3. GW150914, 14 septembre 2015 : deux trous noirs ~29 et ~36 masses solaires, ~1,3 milliard d'années-lumière ; le chirp monte de ~35 à ~250 Hz.
4. Voyager 1, instrument PWS (Plasma Wave Science), PI Donald Gurnett, Université de l'Iowa ; héliopause franchie en août 2012 ; tons ~300 Hz dedans, 2–3 kHz dehors ; orages de plasma oct–nov 2012 et avr–mai 2013.
5. Voyager 1979 : whistlers d'éclairs joviens, première preuve d'éclairs sur Jupiter ; Cassini : foudre de Saturne, SKR.
6. Golden Record 1977 (comité Sagan) : Bach, Chuck Berry, chant de baleine.
7. Persée, Chandra 2003 (Fabian et al.) : ondes de pression, si bémol 57 octaves sous le do médian, ~250 millions d'années-lumière ; sonification NASA 2022 ; facteurs 144×10^15 et 288×10^15.
8. Héliosismologie : SOHO, SDO, BiSON, GONG ; astérosismologie CoRoT, Kepler, TESS.
9. Donald Gurnett (1940–2022), James Van Allen Professor ; archives space-audio.org.
10. Whistlers terrestres écoutés depuis les années 1950.
11. Modes p du Soleil : 0,3–5 mHz, maximum 2–5 mHz, oscillations de cinq minutes (Leighton, Noyes, Simon 1962 ; Deubner 1975) ; précision des fréquences meilleure que 10^-6.
12. Grande séparation Δν ≈ (2∫dr/c_s)^-1 (Vandakurov) ≈ 135–136 µHz pour le Soleil.
13. Sunquakes : Kosovichev & Zharkova 1998 ; fréquence de coupure acoustique ~5 mHz ; HMI montre des sunquakes sur des flares moyennes.
14. CMB : recombinaison ~380 000 ans ; Peebles & Yu 1970 ; c_s = c/√(3(1+R)), R = 3ρ_b/(4ρ_γ) ; Silk 1968 (amortissement).
15. Fréquence plasma f_pe = (1/2π)√(n_e e²/(ε0 m_e)) ; HELIOS : f_pe ~20 kHz à 1 UA, centaines de MHz près de la photosphère ; ion-acoustique ~500 Hz à 1 UA.
16. Ginzburg & Zheleznyakov 1958 (type III) ; Gurnett & Anderson, Science 1976 et JGR 1977 (Helios) ; STEREO/WAVES (Bougeret) ; Reid & Kontar, Nature Astronomy 2021 (LOFAR) ; Solar Orbiter RPW : f_p ~47–58 kHz mesurés.
17. Frise : Kundt 1866 ; Rubens 1905 ; Fletcher–Munson 1933 ; Békésy Nobel 1961 ; Lighthill 1952 ; Edison 1877 ; Rayleigh 1877–1878.
