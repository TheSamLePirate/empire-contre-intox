# Lot 07 — Oreille, sécurité auditive, bioacoustique humaine, salles (ch. 9, 9b, 10)
1. Étrier : le plus petit os du corps ; chaîne pavillon → tympan → osselets → fenêtre ovale → cochlée → organe de Corti.
2. Békésy : onde progressive, tonotopie (base = aigus, apex = graves), Nobel 1961.
3. Kemp 1978 : otoémissions ; cellules ciliées externes = amplificateur actif ; TEOAE / DPOAE en dépistage néonatal.
4. Fletcher & Munson 1933 ; Stevens sone 1936 ; Zwicker, Bark.
5. Implants cochléaires : House, Simmons, Chouard, Clark ; commercialisation large années 1970–80.
6. Le bruit est un facteur de risque cardiovasculaire documenté par l'OMS ; OMS 2018 : trafic routier au-delà de 53 dB Lden et 45 dB la nuit = effets sanitaires.
7. Directive 2003/10/CE et Code du travail art. R4431-2 : 80 dB(A) valeur d'action inférieure, 85 supérieure, 87 limite (oreille protégée) ; crêtes 135 / 137 / 140 dB(C) ; règle d'échange de 3 dB.
8. Durées admissibles : 85 dB(A) 8 h ; 91 dB 2 h ; 94 dB 1 h ; 100 dB 15 min ; 103 dB 7,5 min ; 110 dB ~1,5 min ; 120 dB seuil de douleur.
9. Décret 2017-1244 (France, sons amplifiés) : 102 dB(A) sur 15 minutes glissantes, 118 dB(C).
10. Bouchons « musicien » filtrés −15 à −20 dB ; bouchons mousse SNR 25–35 dB ; règle « 60 % / 60 minutes » est empirique.
11. Perte auditive brutale : à traiter en urgence sous 48 h.
12. f0 homme adulte ~85–180 Hz, femme ~165–255 Hz ; registres modal, fry, falsetto.
13. Formant du chanteur ~2,5–3 kHz (Sundberg).
14. Bande téléphone historique 300–3400 Hz.
15. « Motherese » : f0 plus haut et excursions élargies, fait reproductible.
16. Écholocation humaine : Thaler, Kish ; clics surtout audibles.
17. Bruits du cœur B1 B2 ; phonocardiographie ; tests de Weber et Rinne au diapason.
18. Phoniatrie : jitter, shimmer, voice range profile (VRP).
19. Wallace Clement Sabine (1868–1919), Harvard 1895, Fogg Art Museum, coussins du Sanders Theatre ; T60 = 0,161 V/A ; Boston Symphony Hall ouvert en 1900.
20. Eyring, Norris, Beranek, Barron, Hidaka ; chambres anéchoïques ; RT60 studio < 0,3 s.
