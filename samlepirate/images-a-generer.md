# Images du dossier « Le langage des champs » — état

Le dossier `champs-vecteurs.html` est **autonome visuellement** :

- **Hero** = champ d'écoulement **génératif** (canvas, rendu en direct) — aucune image
  requise. Un repli statique est tiré automatiquement pour `prefers-reduced-motion`.
  Une capture du champ sert d'affiche pour la carte d'index : `assets/champs-vecteurs-hero.jpg`.
- **Diagrammes** des concepts = **SVG géométriques** dessinés dans la page (convention
  de dessin, colline/gradient, source/puits, onde E⊥B, pas∥/pas⊥).
- **Ateliers** = deux **canvas interactifs** (champ de vecteurs + portrait de phase
  Lotka–Volterra).

Si l'on veut **régénérer** une plaque, garder la même direction artistique : nuit
bleu profond `#060814`, turquoise `#43d6c4` (source), corail `#ff6a4d` (puits),
ambre `#f5b14a` (rotation), poussière d'étoiles, lueur douce, **aucun texte** dans
l'image. Chaque plaque a un repli « ◫ Visuel » si le fichier manque.
