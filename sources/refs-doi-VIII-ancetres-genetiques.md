## Notes anti-hallucination DOI

- Moody et al. 2024 LUCA = **`10.1038/s41559-024-02461-1`** (article de recherche), pas le News & Views `…02474-w`.
- Le DOI de Gell-Mann/DOI avec parenthèses n'est pas utilisé dans ce dossier ; pour les DOI avec parenthèses dans les URL (`10.1016/S0968-0004(99)01392-4`), les parenthèses sont encodées dans le lien Markdown.
- Les dates Ève/Adam/LUCA sont **modèle-dépendantes** : citer des fourchettes et les méthodes plutôt qu'une valeur unique.
