# Dossier XVIII — Les Premières Cités (Lalie & Ymir)

Audit factuel du live « Les Premières Cités : Le code source de notre monde »
(Uruk, Ur, Mohenjo-Daro, Jéricho, Gilgamesh, l'invention de l'écriture, la musique
comme ingénierie sociale, la convergence mondiale). Transcription conservée **mot
pour mot** dans `ymir-lalie/premieres-cites/index.html` ; les nuances ci-dessous
sont surfacées en encadrés « anti-intox » **sans** modifier le verbatim.

Vérification par **5 agents de recherche en parallèle** (Uruk + écriture ; Ur /
Mohenjo-Daro / Jéricho ; Gilgamesh ; musique + mythologie ; civilisations globales +
bibliographie). Verdicts : ✅ confirmé · ⚠️ à nuancer · 🔶 débattu · ❌ erroné.

## 1. Uruk & l'invention de l'écriture

| Affirmation (live) | Verdict | Référence |
|---|---|---|
| Uruk, première métropole, Basse-Mésopotamie, IVe millénaire | ✅ | « première grande ville du monde » (Met Museum) |
| ~250 ha à l'apogée « vers 3000 av. J.-C. » | ⚠️ | 250 ha datés plutôt de la **fin de l'Uruk récent ~3100 av. J.-C.** (Uruk IV) |

| Secteurs Eanna (Inanna) et Anu | ✅ | deux districts sacrés majeurs |

## Synthèse

**❌ Erreurs corrigées (encadrés anti-intox dans la page) :**
- **Fortifications de Jéricho** : ~8000 av. J.-C. (tour ~8300–7800, PPNA), **pas 6800**
  (l'erreur figure 3 fois dans le live : fiche Jéricho, sites du Levant, tableau).
- **Conque de Marsoulas** : le chercheur est **Guillaume Fleury** (et non « Guillem Flury »).
- **Théorie des jetons** : l'« empreinte sur la bulle » est **~3500** (contemporaine de
  l'enveloppe), pas 3300 ; les **pictogrammes ~3100**.
- **Bibliographie Gilgamesh** : Aaron **Shaffer** (deux F), pas « Schaffer ».

**⚠️ / 🔶 Nuances surfacées :**
- Uruk 250 ha → ~3100 av. J.-C. ; or d'Ur → provenance débattue ; Mohenjo-Daro
  « fosses septiques » (anachronisme) et « greniers » (terme contesté) ; absence de
  palais = interprétation débattue ; Gilgamesh « vers 2600 » = estimation, « l'une des »
  plus anciennes œuvres, XIIᵉ tablette = appendice ; « objet-paroi » = lecture archéo ;
  Caral cité ~2600 vs aire ~2900–3000 ; 'Ain Ghazal ~3000 hab. = estimation ; édition
  française Payot de Frankfort non confirmée.
